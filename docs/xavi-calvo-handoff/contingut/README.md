# Com preparar els continguts
Per començar n'hi ha prou amb textos en Markdown i els fitxers d'imatge o vídeo originals. Codex els pot convertir al format que ja utilitzi la web.

## Una carpeta per projecte
Duplica projectes/plantilla-projecte/, posa-hi un nom curt sense espais i omple projecte.md. A media/ desa la portada i les imatges en l'ordre que vulguis. No cal preparar-les dins d'un Word ni fer captures de les imatges. Conserva els originals; Codex pot crear-ne còpies optimitzades.

La informació més útil: títol, què era el projecte, què hi vas fer tu, any, eines, portada i ordre de la galeria. Client, crèdits i enllaç al vídeo només si escau.

## Textos de pàgina
Omple pagines/ca.md. Pots començar en català i preparar després es.md i en.md amb la mateixa estructura. Mantén noms de projecte i noms de fitxer estables entre idiomes. Les traduccions pendents s'han de tractar com a pendents.
