# Xavi Calvo — disseny i continguts per a Codex
Set maquetes de referència: Inici, Projectes, detall de projecte, Serveis, Galeria, Sobre mi i Contacte.

## Com fer servir el paquet
1. Descomprimeix aquesta carpeta dins del repositori obert a VS Code, per exemple a docs/xavi-calvo-handoff/.
2. Llegeix DISSENY.md i afegeix els teus fitxers originals seguint recursos/README.md.
3. Enganxa PROMPT-CODEX.md al xat de Codex. Adjunta les maquetes d'Inici i Serveis; indica on són les altres cinc.
4. Revisa primer la capçalera i Inici. Després aplica els components compartits a totes les pàgines.
5. Duplica contingut/projectes/plantilla-projecte/ per cada feina i omple projecte.md. Codex pot adaptar aquests textos al format de dades que ja utilitza la web.

Les maquetes són referències visuals generades. Les escenes, els projectes d'exemple i la foto de rodatge no són treballs acreditats de Xavi. Substitueix-los pel teu material. La web existent no s'ha modificat amb aquest paquet.
